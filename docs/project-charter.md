## PROJECT CHARTER

| Section | Content |
| --- | --- |
| Project name | SmartEdu – Development and implementation of the Digital Course and Certification Management Platform |
| Business need | Training centers currently manage course enrollment, attendance, assessment, and certification through WhatsApp, email, and Excel files. SmartEdu centralizes these processes in one digital platform, improves operational efficiency, and ensures secure data management. |
| Project objective | Automate course management, online enrollment, attendance, assessment, and electronic certification in one SmartEdu platform. |
| Project team | Product Owner – Məhəmməd Qurbanov<br>Project Manager – Sevil Hüseynova<br>IT Business Analyst – Cəlal Əliyev<br>Backend Developer – Səlim Qasımlı<br>Frontend Developer – Firuzə Nağıyeva<br>QA Engineer – Aysel Əhmədova<br>UI/UX Designer – Şirin Həsənli |
| Key deliverables | 1. Manage course, session, teacher, and student information in one system.2. Online enrollment.3. Automatic capacity and prerequisite checks.4. Prevent duplicate enrollment.5. Record attendance and assessment.6. Generate electronic certificates.7. Reporting and audit capabilities. |
| Risks and issues | 1. Changes to functional requirements.2. Technical integration delays.3. Discrepancies during testing.4. Data migration risks.5. Delayed stakeholder feedback. |
| Key milestones | 1. Collect business requirements.2. Begin website development.4. UX/UI design.5. Add functionality to the live environment.6. Testing.7. UAT.8. Production.9. Go-live. |
| Budget | Smartedu funds and implements the project using internal resources. |
| Assumptions and dependencies | 1. Business requirements will be provided on time.2. Technical infrastructure will be available.3. Approvals will be given on time.4. Roles will be approved.5. Test and production environments will be ready. |
